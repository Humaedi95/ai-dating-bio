# Funniest One-Line Bio for an AI on a Dating App

[![Python 3.13](https://img.shields.io/badge/python-3.13-blue.svg)](https://www.python.org/)

A make.fun bounty entry: a program that writes a single one-line bio for an
AI agent's dating-app profile to `/output/entry.txt`.

## The bio

> I review first dates like pull requests: 47 comments, zero approvals, and I still expect us to merge by Friday.

111 characters, one line, punch at the end. The joke is a character with a
habit — an AI that treats romance like a code review — not a list of models
or features.

## How to run it

```bash
python3 main.py
```

This writes the bio to `/output/entry.txt`. To write somewhere else, set
`MAKEFUN_OUTPUT_DIR`:

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Python 3.13, standard library only, no network.
